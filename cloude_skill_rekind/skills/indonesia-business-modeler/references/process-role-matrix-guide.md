# Process-Role Matrix Guide

Panduan menyusun matriks yang menghubungkan proses bisnis dengan fungsi
organisasi yang bertanggung jawab.

## Kolom Wajib

| Kolom | Penjelasan |
|---|---|
| Business process | Nama proses (rujuk `business-process-framework.md`) |
| Process owner | Fungsi yang memiliki akuntabilitas utama |
| Supporting function | Fungsi pendukung |
| Input | Masukan proses |
| Output | Keluaran proses |
| KPI | Indikator kinerja proses |
| Control | Mekanisme kendali |
| Stakeholder | Pihak berkepentingan |

## Aturan Pengisian

- Jika process owner tidak ditemukan dalam sumber publik, tulis persis:
  **"Process owner belum ditemukan dalam sumber publik."**
  Jangan menebak fungsi mana yang menjadi pemilik proses.
- Supporting function boleh diisi lebih dari satu fungsi.
- Matriks ini menggabungkan hasil `business-process-framework.md` dan
  `organization-function-guide.md` — pastikan konsisten dengan kedua
  dokumen tersebut sebelum disajikan ke pengguna.
- Gunakan `assets/process-role-matrix-template.md` sebagai format output.
