# Organization Function Guide

Panduan memetakan fungsi organisasi perusahaan (bukan individu/pegawai).

## Atribut Wajib per Fungsi

| Atribut | Penjelasan |
|---|---|
| Nama fungsi | Mis. Divisi Operasi, Departemen Procurement |
| Tujuan | Alasan fungsi ini ada |
| Tanggung jawab | Cakupan kerja utama |
| Proses yang ditangani | Rujuk proses dari `business-process-framework.md` |
| Input | Apa yang diterima fungsi ini |
| Output | Apa yang dihasilkan |
| Stakeholder | Pihak yang berkepentingan (internal/eksternal) |
| KPI | Indikator kinerja fungsi |
| Decision authority | Keputusan yang dapat diambil fungsi ini |
| Hubungan dengan fungsi lain | Koordinasi, pelaporan, dependency |

## Label Sumber (Wajib)

- `OFFICIAL JOB DESCRIPTION` — berasal dari dokumen resmi perusahaan
  (struktur organisasi resmi, job posting resmi, annual report).
- `GENERAL INDUSTRY RESPONSIBILITY` — praktik umum fungsi tersebut di
  industri sejenis, bukan spesifik perusahaan.
- `AGENT INFERENCE` — hasil analisis/penalaran agent berdasarkan konteks,
  bukan dari dokumen langsung.
- `INFORMATION NOT AVAILABLE` — informasi tidak ditemukan; jangan diisi
  dengan asumsi.

## Prinsip Penyusunan

- Jangan menyamakan struktur organisasi generik industri dengan struktur
  resmi perusahaan tertentu tanpa label.
- Jika struktur organisasi berbeda antar-sumber (mis. annual report vs
  website), tampilkan perbedaan dan tandai `REQUIRES COMPANY VALIDATION`.
- Fungsi yang tidak dapat dikonfirmasi keberadaannya tetap boleh
  disebutkan sebagai referensi umum industri, dengan label yang sesuai —
  bukan dihapus begitu saja, agar pengguna tahu apa yang perlu divalidasi.
- Untuk kebutuhan job-desk level lebih rinci (individu/posisi), lihat
  `job-desk-analysis-guide.md`.
