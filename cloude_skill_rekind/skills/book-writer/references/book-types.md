# Book Types

Gunakan panduan ini untuk menyesuaikan struktur buku berdasarkan jenisnya.

## Handbook

Prioritaskan:

- langkah praktis;
- navigasi cepat;
- checklist;
- FAQ;
- troubleshooting;
- referensi singkat.

## Learning Module

Prioritaskan:

- tujuan pembelajaran;
- penjelasan bertahap;
- contoh;
- latihan;
- rangkuman;
- evaluasi.

## Technical Book

Prioritaskan:

- istilah teknis;
- konsep dasar;
- prosedur;
- diagram;
- spesifikasi;
- batasan;
- referensi.

## Onboarding Guide

Prioritaskan:

- pengenalan organisasi;
- peran;
- proses awal;
- aktivitas hari atau minggu pertama;
- escalation path;
- FAQ;
- checklist.
