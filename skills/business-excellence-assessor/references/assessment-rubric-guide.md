# Assessment Rubric Guide

Panduan ini mencegah scoring hanya berdasarkan keberadaan dokumen.

## 1. Enam dimensi implementasi

| Dimension | Pertanyaan utama | Evidence examples |
|---|---|---|
| Approach | Apakah metode, proses, aturan, atau sistem dirancang dengan jelas? | policy, framework, SOP, method, role definition |
| Deployment | Apakah approach benar-benar diterapkan pada scope yang dinilai? | implementation record, observation, completed activity, unit coverage |
| Measurement | Apakah pelaksanaan dan output diukur dengan definisi yang jelas? | KPI, dashboard, data record, review result |
| Learning | Apakah hasil digunakan untuk correction, improvement, atau innovation? | action log, lessons learned, improvement evidence |
| Integration | Apakah praktik terhubung dengan strategi, proses, fungsi, dan keputusan? | KPI cascade, integrated governance, cross-unit workflow |
| Results | Apakah terdapat target, actual, trend, comparison, dan sustained outcome? | performance trend, benefit realization, customer/people/process result |

Tidak semua subkriteria membutuhkan bobot dimensi yang sama. Namun, subkriteria
maturity tinggi umumnya membutuhkan lebih dari sekadar Approach.

## 2. Default anchor 0–100

| Score band | Default anchor |
|---|---|
| 0–20 | approach tidak jelas/ad hoc; deployment tidak terbukti |
| 21–40 | approach sebagian; deployment terbatas dan tidak konsisten |
| 41–60 | approach terdokumentasi; deployment cukup luas; measurement mulai ada |
| 61–80 | deployment konsisten; measurement dan learning berjalan; integration cukup kuat |
| 81–100 | integrated, adaptive, continuously improved, and sustained results demonstrated |

Gunakan anchor framework pengguna bila tersedia.

## 3. Evidence gate

- **Approach-only evidence:** maksimum default Level 3 bawah, kecuali framework
  pengguna menentukan lain.
- **No deployment evidence:** jangan menyatakan praktik managed/optimized.
- **No results evidence:** kategori Results adalah N/A atau rendah sesuai rubric;
  jangan menyalin score process ke Results.
- **Conflicting evidence:** score range dan confidence diturunkan.
- **Old evidence:** pertimbangkan recency dan relevansi periode.

## 5. Preliminary document assessment

A document-only assessment commonly supports Approach and planned Deployment.
Do not infer actual implementation or results without records, interviews, or
observations.
